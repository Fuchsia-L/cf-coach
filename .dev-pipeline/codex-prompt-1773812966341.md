## Project Overview

Build a local Web Dashboard on top of the existing `cf` CLI by first refactoring shared helpers into a reusable `src/utils.js`, then adding a dependency-free Node.js HTTP server with JSON endpoints backed only by local cache data, and finally delivering a modular dark-theme frontend that visualizes profile, rating trends, roadmap progress, tag performance, rating buckets, weakness analysis, recommendations, and submission timeline in an architecture that is easy to extend with new panels and APIs.

## Current Phase: Build dashboard shell and core panels

Create a modular dark-theme frontend using plain HTML, CSS, and vanilla JS, organized so each dashboard panel has its own render function. Implement the profile bar, rating trend chart, roadmap panel, tag ability chart, and rating bucket chart, with fetch-based loading from the JSON APIs and responsive desktop-first layout that remains usable at 1024px width.

## Acceptance Criteria

1. The dashboard page loads without external JS/CSS libraries and fetches data from local `/api/*` endpoints.
2. The layout renders correctly in a desktop viewport and remains usable at `1024px` minimum width.
3. Profile bar shows handle, CF-colored rating, rank, total AC, total submissions, and attempted problem count.
4. Rating trend panel renders a line chart with non-uniform time spacing on the x-axis and rating on the y-axis.
5. Rating trend tooltip shows contest name and rating delta on hover.
6. Roadmap panel renders 20 stages with name, tag, progress, current-stage highlight, completed-state styling, and not-started styling.
7. Tag ability panel renders horizontal bars sorted by accepted count descending, with separate accepted and attempted bars plus acceptance-rate labels.
8. Rating bucket panel renders accepted-count bars for `800/900/1000/.../1600+` using Codeforces rating colors.
9. Frontend code is organized into reusable rendering functions/modules so adding a new panel does not require rewriting the whole page.
